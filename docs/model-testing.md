# 模型测试与保存门槛

日期：2026-09-22，macOS Apple Silicon。

## 实现

- 新增/编辑/复制表单默认禁止保存，主动测试成功后解锁。任何字段变化或重测失败都会重新禁止保存，回车提交同样受限。
- 测试期间可修改或取消表单，迟到的结果不会用于新配置或新打开的表单。
- 模型卡片在编辑、复制后增加测试按钮；未测试无圆圈，通过为绿圈，失败为红圈，支持耗时与失败原因提示。
- 测试结果与所有模型字段绑定，只保留在当前应用会话，不在加载列表时自动测试。表单保存后，其通过状态延续到对应卡片。
- Rust 使用独立客户端发送一次文本 test，分别调用 Chat Completions、Responses、Anthropic Messages。不使用登录 Cookie，也不跟随重定向；普通模型表单要求先填写 API Key。
- 超时 30 秒、输出限额 256 Token、响应上限 1 MiB。HTTP 200 但正文为错误、HTML、空回复或不符合所选协议时均判定失败。错误提示不回显密钥、原始响应和请求 URL。

## 提示样式更新

成功提示仅显示“测试通过，耗时0.12 秒”，时间统一换算为秒，保留两位小数。结果提示 5 秒后自动隐藏，行末提供 ×；再次测试重新计时。隐藏提示不会清除测试状态、绿圈或保存资格，切换页面后已关闭的提示也不会重新出现。测试过程中的进度行保留到请求结束。

浅色模式测试绿圈调整为 #16a34a，深色模式为 #22c55e；成功文字采用对应的高对比绿色。

## 编辑模型的平台模型清单

添加或编辑模型时，先填写必填的 API Key，再使用模型 ID 下拉选择器。编辑页仅在已有 API Key 时自动获取模型清单。OpenAI 两种协议访问基础地址下的 `/models`；Anthropic 访问 `/v1/models` 并读取分页。接口依据：[OpenAI 模型接口](https://platform.openai.com/docs/api-reference/models)、[Anthropic 模型清单](https://platform.claude.com/docs/en/api/models/list)。

支持手动刷新。修改协议、地址或密钥后清空旧清单与当前选择，需要点击刷新并重新选择；过期请求不会覆盖新配置的清单。平台未返回原模型时提示重新选择，加载失败或空清单时禁止测试及保存，不回退为手输模型 ID。选中模型后仍须推理测试通过才能保存。

清单请求不携带登录 Cookie、不跟随重定向、不持久化密钥；完整请求限制 30 秒、累计响应 1 MiB、最多 100 页。浏览器演示明确提示无法获取清单，实际请求由桌面应用执行。

新增验证覆盖：自动获取与选择、模型不在清单、加载失败重试、配置修改后的旧响应丢弃；Rust 模拟平台接口验证三种协议的鉴权、去重排序、Anthropic 分页及异常响应脱敏。
